github-actions-vs-gitlab-ci-demo

Same Node.js pipeline. Two CI platforms. Side by side.

Companion repository for a blog post comparing GitHub Actions and GitLab CI/CD. The same build-test-deploy pipeline for this small Express app is implemented twice — once in .github/workflows/ci.yml and once in .gitlab-ci.yml — so you can read them next to each other and see exactly where the two platforms diverge.

Pipeline, two ways

GitHub Actions .github/workflows/ci.yml
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
      - run: npm install
      - run: npm test
GitLab CI/CD .gitlab-ci.yml
stages:
  - test
  - build
  - deploy

default:
  image: node:20
  cache:
    paths:
      - node_modules/

test:
  stage: test
  script:
    - npm install
    - npm test
